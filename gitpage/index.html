// 01 · capabilities

Engineered for teams that ship fast, but won't ship vulns.

Built on Semgrep · ESLint · Bandit
F.01

340+ curated rules

Coverage for injection, deserialization, weak crypto, secrets, IDOR, SSRF, prototype pollution, and more. Every rule ships with a PoC, a fix and a CWE/OWASP reference.

F.02

Runs in any pipeline

GitHub Actions, GitLab CI, Jenkins, Azure DevOps. SARIF output that feeds Defender, GitHub Security and Code Scanning with zero glue.

F.03

Multi-language

JS/TS, Python, Go, Java, C#, Ruby, PHP, Kotlin, Swift, Rust, Terraform and Dockerfile. Rule packs can be toggled per language.

F.04

Severity + autofix

Every rule has a calibrated severity and, when safe, an autofix suggestion. PR triage takes seconds, not hours.

F.05

Policy-as-code

Allowlists, denylists and exceptions versioned in YAML. Auditable, reviewable and revertible like any other code.

F.06

IDE-ready

Plugins for VS Code, JetBrains and Neovim. Real-time feedback as the vuln is typed — not after it's merged.

// 04 · quick start

From zero to first scan in 60 seconds.

$ pip install · $ semgrep

Install and run

Point the pack at your repo. It auto-detects languages, loads only the relevant rules and returns SARIF + a human-readable report. Supports path excludes, baseline against a base commit, and --severity for PR gating.
