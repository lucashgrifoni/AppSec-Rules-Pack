# Code of Conduct

## Expected Behavior

Participants are expected to communicate respectfully, give and receive technical
feedback in good faith, and keep discussions focused on the project and its users.

This project does not tolerate harassment, intimidation, personal attacks, or
discriminatory language in issues, pull requests, discussions, commits, or other
project spaces.

## Security And Privacy

Do not post secrets, credentials, private vulnerability details, customer data,
proprietary source code, or exploit payloads from systems you do not own. Security
issues must follow the private reporting path in `SECURITY.md`.

## Enforcement

The maintainer may remove comments, close discussions, block participation, or take
other moderation action when behavior creates risk for contributors or the project.

If you need to report a conduct issue, contact the maintainer privately with the
relevant context and links.
